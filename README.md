# 🎭 Clube Recreativo da Sapataria

Website oficial do Clube Recreativo da Sapataria - Um espaço de amizade, tradição e convívio para toda a comunidade.

## 📋 Características

- ✨ Hero section com call-to-action
- 📅 Secção de próximos eventos
- 🖼️ Galeria de imagens
- 📧 Formulário de contacto
- 📱 Design responsivo (mobile-first)
- 🎨 Tailwind CSS para estilos modernos
- ⚡ Vite para desenvolvimento rápido

## 🚀 Como Começar

### Pré-requisitos
- Node.js (v16 ou superior)
- npm ou yarn

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/mariasilva0000/Clube-Recreativo-da-Sapataria.git
cd Clube-Recreativo-da-Sapataria
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

O site abrirá automaticamente em `http://localhost:3000`

### Build para produção
```bash
npm run build
```

Os arquivos otimizados estarão na pasta `dist/`

## 🎯 Funcionalidades
